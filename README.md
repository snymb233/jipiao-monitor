# 📖 使用指南：改成你自己的行程监控

本项目可完全在 **GitHub 云端免费** 运行，无需自己开电脑。只需 4 步即可监控你自己的航线和日期。

## 第 1 步：创建你自己的仓库

两种方式任选其一（都需要你有 GitHub 账号）：

- **方式 A（推荐）**：在本仓库页面点右上角绿色 **"Use this template"** → "Create a new repository"，即可复制一份属于自己的仓库。
- **方式 B**：点右上角 **Fork**。注意 Fork 后需要进入你仓库的 **Actions 标签页，手动点 "Enable workflows"** 才会启用 Actions。

创建后，你就拥有了一份独立的仓库，后续所有改动都在你自己的仓库里进行。

## 第 2 步：修改 config.yaml（核心配置）

在你仓库中打开 `config.yaml`，编辑以下字段：

```yaml
# README 标题与副标题（会显示在仓库首页，可自定义）
title: 我的机票监控
subtitle: 出发地 → 目的地 · 出行日期

routes:
  - from: SHA           # 出发机场三字码（如 SHA 上海虹桥 / PVG 浦东 / PEK 北京首都）
    from_name: 上海      # 显示用的中文名
    to: KMG             # 到达机场三字码
    to_name: 昆明
    dates:              # 要监控的出发日期，可写多个
      - "2026-10-01"
      - "2026-10-02"
    alert_threshold: 600  # 低于此价在 README 标 🔥（元，0 = 不启用）
```

说明：

- **三字码**：IATA 机场代码，可在 [航旅纵横](https://www.umetrip.com/) 或搜索引擎查询，如 西安=SIA、咸阳国际机场、成都双流=CTU、昆明=KMG。
- 组合数量 = 航线数 × 日期数。每 20 分钟抓 1 个组合，所以组合越多，全量刷新一轮的时间越长（例如 20 个组合约 6~7 小时一轮）。
- 改完配置后，**记得把 `data/cursor.json` 里的 index 改回 0**（或直接删掉该文件），否则会从旧进度继续抓。

## 第 3 步：重置数据（可选但建议）

仓库里附带的是原作者的监控数据，建议清掉重新开始：

1. 进入 `data/` 目录，删除 `prices.csv` 和 `cursor.json`（网页上打开文件 → 右上角垃圾桶图标 → Commit）。
2. `README.md` 会在下一次抓取后自动重新生成，不用手动改。

## 第 4 步：启动监控

1. 进入你仓库的 **Actions** 标签页。
2. 左侧选择 **"机票价格监控"** 工作流。
3. 右侧点 **"Run workflow"** → **"Run workflow"** 确认。
4. 之后无需再管：每次运行会自动抓取 1 个组合、提交数据，然后在下一个 20 分钟整点自动触发下一轮，无限循环。

## 其他说明

- **每日比价**：`compare.yml` 每天上午 10 点（北京时间）自动用同程复核当前最便宜的 12 条航线，作为交叉验证。它同时兼任"链守护"——如果监控链意外中断，会自动重新拉起。
- **风控注意**：数据源是途牛的接口，同一 IP 短时间内高频请求会触发风控。本项目每 20 分钟抓 1 个组合的节奏是实测安全的，**请不要调快**，也不要同时挂多个仓库抓同一平台。
- **本地运行（可选）**：如果不只想云端跑，也可以 clone 到本地 `pip install -r requirements.txt` 后执行 `python main.py`，配置方法见 `config.example.yaml` 内的注释。但注意本机运行要考虑电脑开机时间。
- **费用**：公开仓库 GitHub Actions 免费不限量；如果你想转私有，注意私有仓库每月只有 2000 分钟免费额度，而本项目的链式调度会持续占用运行时长（约 1440 分钟/天），**私有仓库跑不动**，请保持公开。
- **合规**：数据仅供个人出行参考，请勿用于商业用途或高频爬取。

## 常见问题

**Q：改了 config.yaml 怎么生效？**
下一次运行自动生效（最迟 20 分钟），无需重启。

**Q：某条航线一直显示"待抓"？**
组合较多时需要等一轮完整刷新（约 2 天/百组合），也可以临时删减 routes 加速首轮覆盖。

**Q：Actions 页面显示工作流被禁用 / 不运行？**
Fork 的仓库需要手动启用 Actions（第 1 步方式 B 的说明）；链式调度依赖 `permissions: actions: write`，请不要删除 monitor.yml 里的 permissions 段。

**Q：想提醒我降价怎么办？**
方案 1：盯着 README 的 🔥 标记；方案 2：配置 `notifier.serverchan`（Server酱微信推送，本地模式有效），或在 Actions 里加一步调用你自己的 webhook。
